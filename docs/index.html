ADB Install מתקינה קובצי אנדרואיד בטלפון שמחובר למחשב, ומנהלת אותו מ-Windows: אפליקציות, קבצים, שיקוף מסך עם מקלדת עברית, צילום מסך ועוד. ‏adb ו-scrcpy כבר בפנים, אין צורך להתקין שום דבר נוסף.

בלי שורת פקודה

קובצי XAPK ו-APKS הם כמה קובצי APK וקובצי OBB ארוזים יחד. ADB Install פותחת אותם, בוחרת את החלקים שמתאימים למעבד של הטלפון, מתקינה, ומעתיקה את קובצי ה-OBB למקומם.

> adb install-multiple base.apk split_config.arm64_v8a.apk split_config.xxhdpi.apk split_config.he.apk
> adb push main.1204.com.game.obb /sdcard/Android/obb/com.game/

סיור בתוכנה

אלה המסכים האמיתיים של ADB Install. לחיצה על תמונה פותחת אותה בגודל מלא.

טלפון עם root: מתקינים בלי לאבד נתונים

גרסה ישנה יותר, או קובץ עם חתימה אחרת, אפשר להתקין רק אחרי שמסירים את האפליקציה, וההסרה מוחקת את הנתונים שלה. בטלפון עם root, ADB Install שומרת אותם בדרך.

  1. גיבויהאפליקציה והנתונים שלה נשמרים במחשב
  2. הסרהרק אחרי שהגיבוי הושלם
  3. התקנההקובץ החדש נכנס לטלפון
  4. החזרת הנתוניםכולל Android/data, ‏obb וההרשאות

ההתקנה נכשלה? הגרסה הקודמת חוזרת לטלפון, עם הנתונים.

גיבוי אפליקציות עם הנתונים

מעמוד האפליקציות אפשר לגבות אפליקציה אחת, כמה או את כולן. כל גיבוי הוא קובץ .apks אחד, ולחיצה כפולה עליו מתקינה את האפליקציה ומחזירה את הנתונים, גם בטלפון אחר עם root.

ועוד בתוכנה

הכול מהחלון הראשי, שנפתח מתפריט התחל.

צילום והקלטת מסך

צילום של מסך הטלפון נשמר ישר למחשב, וכך גם הקלטת וידאו.

יומן מערכת

‏logcat חי, עם סינון לפי אפליקציה, כדי להבין למה משהו קורס.

חיבור אלחוטי

עבודה עם הטלפון דרך ה-Wi-Fi: מעבר מחיבור בכבל, או צימוד עם קוד באנדרואיד 11 ומעלה.

כמה טלפונים יחד

כשמחוברים כמה מכשירים, בוחרים באיזה להתקין, או מתקינים בכולם בבת אחת.

שגיאות בעברית פשוטה

כשהתקנה נכשלת מופיע הסבר ברור, וכשהחתימה שונה מוצעת הסרה והתקנה מחדש.

מהתפריט של הקליק הימני

‏"התקן עם ADB" בקליק ימני על קובץ, גם בלי לשנות את התוכנה שפותחת קובצי APK.

התקנה בארבעה צעדים

  1. מורידים את תוכנת ההתקנה

    הקובץ ADB-Install-Setup.exe מהכפתור שבצד, או מעמוד הגרסאות ב-GitHub.

  2. מריצים אותה

    לא צריך הרשאות מנהל: התוכנה מותקנת למשתמש הנוכחי בלבד. הקובץ לא חתום דיגיטלית, ולכן Windows עשוי להציג אזהרת SmartScreen. במקרה כזה: "מידע נוסף" ← "הפעל בכל זאת".

  3. מפעילים ניפוי באגים בטלפון

    בהגדרות הטלפון: מידע על הטלפון ← 7 הקשות על "מספר Build" פותחות את אפשרויות המפתחים. שם מפעילים "ניפוי באגים ב-USB", מחברים בכבל ומאשרים את המחשב בטלפון.

  4. לחיצה כפולה על קובץ APK

    חלון ההתקנה מציג את שם האפליקציה, האייקון, הגרסה והגודל, ומשווה לגרסה שכבר מותקנת בטלפון. בסיום אפשר לפתוח את האפליקציה מיד.
